# 微任务 P1-2a：前端任务数据层（api/tasks.ts + queries/tasks.ts）

背景：AI_Coding_Center（本工程）前端已接入鉴权（P0-3）+ api/client.ts（fetch 封装：error envelope 解析 + Idempotency-Key + get/post 等）。主工程 REST 已实现任务端点（P1-1a/b/c）：`GET /api/v1/tasks`（limit/hasMore 分页 + status/requirementId/q 过滤）、`GET /tasks/{id}`、`POST /tasks`、`POST /tasks/{id}/assign|execute|retry|cancel`、`PATCH /tasks/{id}`。本任务：前端任务**数据层**（不碰 UI）。

## 范围（严格）

### 1. 类型（src/types.ts 追加或新文件 src/api/tasks-types.ts）
REST Task DTO（对齐主工程返回）：
```ts
export interface TaskDto {
  id: string
  title: string
  summary: string
  status: string            // pending|assigned|awaiting_approval|running|succeeded|failed|cancelled
  priority: string | null
  requirementId: string | null
  assignee: string | null
  assigneeKind: string | null
  progress: number
  tokenBudget: number
  tokenUsed: number
  contextUsage: number | null
  executionMode: string | null
  tags: string[]
  updatedAt: string
  version: number
  allowedActions: string[]  // edit|execute|cancel|approve|rejectChanges|assign
}
```
列表响应：`{ data: TaskDto[], page: { nextCursor: string|null, hasMore: boolean } }`

### 2. api 函数（src/api/tasks.ts 新文件，用 src/api/client.ts）
- `listTasks(params?: { status?: string; q?: string; limit?: number; cursor?: string })` → `{ data, page }`
- `fetchTask(id: string)` → TaskDto
- `createTask(input: { requirementId: string; title: string; spec?: string; tokenBudget?: number })` → TaskDto（POST，idempotent：client 自动生成 Idempotency-Key）
- `assignTask(id: string, input: { agentId?: string; squadId?: string })` → TaskDto
- `executeTask(id: string)` → `{ task: TaskDto, executionId: null, approvalId: null }`
- `cancelTask(id: string)` → TaskDto
- 401/409 处理：ApiClientError 直接抛（调用方处理）

### 3. React Query hooks（src/queries/tasks.ts 新文件）
- `tasksKeys`（query key 工厂：`["tasks", filters]` / `["task", id]`）
- `useTasks(filters?)`——useQuery(listTasks)
- `useTask(id)`——useQuery(fetchTask, enabled: !!id)
- `useCreateTask()` / `useAssignTask()` / `useExecuteTask()` / `useCancelTask()`——useMutation + onSuccess 失效 `tasksKeys.all` + `["task", id]`
- 统一 handleApiError(e) → 返回 message（e instanceof ApiClientError ? e.message : "操作失败"）

### 4. 测试（src/api/tasks.test.ts）
- mock global.fetch：
  - listTasks 成功解析 { data, page }
  - fetchTask 404 → ApiClientError（code=NOT_FOUND）
  - createTask 409 → ApiClientError（code=STATE_CONFLICT）
  - cancelTask 幂等头存在（Idempotency-Key 非空）
- 用 vi.stubGlobal('fetch', ...) 模式（参考现有 App.test.tsx 的 vi.mock 风格）
